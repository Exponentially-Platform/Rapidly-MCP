# Rapidly MCP 2.0.0

Published to the [official MCP Registry](https://registry.modelcontextprotocol.io/v0.1/servers/co.rapidly%2Frapidly/versions/2.0.0) on 5 September 2026. The Registry confirms this version is active and latest.

Rapidly MCP now gives agents one clear path from an idea to the first experiment worth building.

The standard connection has seven tools. `test_idea` saves the idea, Lean Canvas, measurable hypothesis and three to five complete experiment options. It recommends the easiest credible first test for the riskiest assumption and generates one build prompt for that recommendation. The other options remain saved for later.

Three direct method tools remain available through the advanced connection when Canvas, hypothesis or experiment-stage control is useful.

This is a breaking catalogue change. The former 21-tool catalogue has been replaced by the seven standard tools and three advanced method tools. Retired tool names are no longer callable. Rapidly's trusted backend and human editing functions remain in place; they are simply no longer exposed directly to agents.

New trial buckets start with five ideas. Existing higher trial buckets and explicit overrides are not reduced. Paid accounts continue to receive ten ideas per paid seat each calendar month.

This release is Registry package `2.0.0`. Rapidly's live service implementation continues to report version `1.0`; the live `tools/list` response is the authority for the tools available to each connection.

See [what Rapidly can do](docs/tools.md) and the [setup guide](docs/quickstart.md).

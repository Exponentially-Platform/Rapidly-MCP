# Security

Email suspected security problems to [hello@rapidly.co](mailto:hello@rapidly.co) with the subject `Security report: Rapidly MCP`.

Include the affected flow, reproduction steps and possible impact. Don't include active credentials or customer data. Ask for a secure transfer method if the evidence is sensitive.

Please don't open a public issue, publish the problem before coordinated disclosure, or test accounts and teams you don't own or have permission to assess.

Rapidly uses HTTPS. Personal tokens are shown once and stored as a hash. OAuth users approve the team and requested access. Rapidly checks the credential, team membership and tool access on each request.

Read the [Rapidly Privacy Policy](https://www.rapidly.co/privacy) before using confidential company or customer information.

# Support

For setup help, account questions or product feedback, email [hello@rapidly.co](mailto:hello@rapidly.co).

Before writing, check:

- [Setup instructions](docs/quickstart.md)
- [Example prompts](docs/examples.md)
- [Troubleshooting](docs/troubleshooting.md)

For technical problems, include:

- AI agent and version;
- operating system;
- connection type, OAuth or personal token;
- approximate time and timezone;
- the stage that failed;
- the error text, with private details removed.

Don't send personal tokens, OAuth tokens or customer data.

Report suspected security problems privately using [SECURITY.md](SECURITY.md).
